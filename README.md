🛥️ Iate Club — Aluguel de Barcos

## 📖 Sobre o Projeto

O **Iate Club** é um projeto web estático desenvolvido para apresentar uma empresa fictícia de aluguel de embarcações de luxo. O site conta com seções informativas detalhadas sobre destinos exclusivos e a frota disponível, entregando um layout sofisticado, moderno e responsivo.

Este projeto foi construído com fins educacionais, servindo para praticar a estruturação de páginas utilizando **HTML semântico**, estilização avançada com **CSS puro** e organização de código limpo.

## ✨ Funcionalidades e Seções

- **Hero Section:** Apresentação impactante com chamada para ação (CTA).
- **Frota de Luxo:** Vitrine de embarcações disponíveis para locação.
- **Destinos:** Destaque para os principais locais de navegação.
- **Seção Institucional / Sobre:** Informações de credibilidade da empresa.
- **Design Responsivo:** Adaptado para diferentes tamanhos de tela.

---

## 🛠️ Tecnologias Utilizadas

As seguintes tecnologias e conceitos foram aplicados no desenvolvimento:

* **HTML5** (Tags semânticas para melhor acessibilidade e SEO)
* **CSS3** (Flexbox, Grid Layout, variáveis CSS e estilização customizada)
* **Git & GitHub** (Controle de versão)
